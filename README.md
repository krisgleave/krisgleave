# Hi, I'm Kris 👋

### FPV Pilot | Filmmaker | Open-Source Developer

Based in Preston, UK 🇬🇧

I create free, open-source software for FPV pilots, helping make
video workflows, telemetry and flight recordings easier to manage.

I'm also the creator behind **KrisTalksTech**, where I review FPV
drones, cameras, radio systems and the latest technology.

## 🚀 My Open-Source Projects

### 🎯 [OSD Editor](https://github.com/krisgleave/osd-editor)
A macOS application for working with recorded FPV OSD and telemetry,
including DJI SRT and BETAFPV P1 data.

### 🎬 [DVR Remaster](https://github.com/krisgleave/dvr-remaster)
A macOS application for improving and restoring FPV DVR footage.

### 📁 [P1 Transfer](https://github.com/krisgleave/p1-transfer)
A macOS application for transferring and managing BETAFPV P1 recordings.
